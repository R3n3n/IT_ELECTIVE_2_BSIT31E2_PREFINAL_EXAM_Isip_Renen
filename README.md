# Renen H. Isip - BSIT 31E2

## **IT Elective 2 — Web Systems and Technologies — Prefinal Examination**

## About the project

This repository consists of my prefinal exam. It is an **ASP.NET Web Core MVC** web application that displays 20 multiple choice questions
and my answer for each question. There was no database used for this web application, since all data were stored under `ExamData.cs`.

## How to run the application
1. Open the repository
2. Copy the link of the repository
3. Open Visual Studio
4. Clone the repository
5. Click `F5` or the run button
6. The web application should now be running
